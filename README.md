# EYA 3D Builder

Une application web puissante pour la modélisation, simulation et rendu 3D, inspirée par les fonctionnalités de Blender3D.

## 🎨 À propos

EYA 3D Builder est une solution web complète permettant de créer, modifier et simuler des modèles 3D directement depuis votre navigateur. Conçue pour être intuitive et performante, elle offre une expérience similaire aux outils de modélisation professionnels.

## ✨ Fonctionnalités principales

- **Modélisation 3D** - Créez et éditez des objets 3D avec une interface intuitive
- **Simulation Physique** - Simulez le comportement des objets avec physique réaliste
- **Rendu Studio** - Profitez d'un rendu 3D professionnel avec éclairage avancé
- **Rendu performant** - Profitez d'un rendu 3D optimisé et fluide en temps réel
- **Interface moderne** - Contrôles ergonomiques et accessibles
- **Web-based** - Aucune installation nécessaire, accès depuis n'importe quel navigateur

## 🛠️ Technologie

- **TypeScript** - Code robuste et type-safe (99.6%)
- **Framework web moderne** - Approche contemporaine du développement frontend
- **Architecture scalable** - Préparée pour la croissance et l'évolution
- **Moteur physique** - Simulation réaliste des interactions 3D
- **Rendu avancé** - Technologies de rendu studio professionnel

## 🚀 Démarrage rapide

### Prérequis

- Node.js (v18+)
- npm ou yarn

### Installation

```bash
# Cloner le repository
git clone https://github.com/chadest/EYA3D-BUILDER.git
cd EYA3D-BUILDER

# Installer les dépendances
npm install

# Lancer l'application en développement
npm run dev
```

### Build pour la production

```bash
npm run build
npm run preview
```
